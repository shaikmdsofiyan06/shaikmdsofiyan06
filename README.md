### Updating Your Stats

`assets/stats.svg`, `assets/langs.svg`, and `assets/trophies.svg` are **static, locally generated files** — they don't call any live API when someone views your profile, so they never break from third-party rate limits.

The numbers in them right now are placeholders (GitHub's public API was rate-limited when this was generated). To refresh them with your real numbers:

1. Open `build/gen_cards.py`
2. Edit the `rows` / `langs` / `trophies` values with your real stats
3. Run `python3 gen_cards.py` and re-commit the regenerated SVGs in `assets/`

You can re-run this any time your stats change, or wire it into a scheduled GitHub Action (same pattern as `github-snake.yml`) if you'd like it fully automatic.
